# Binary Search

This folder contains Binary Search problems solved as part of my **90 Days DSA Challenge**.

Binary Search is one of the most fundamental searching algorithms. It works on **sorted arrays** by repeatedly dividing the search space in half, achieving a time complexity of **O(log n)**.
