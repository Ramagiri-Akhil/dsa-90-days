# Dynamic Programming

This folder contains Dynamic Programming problems solved as part of my **90-Day DSA Challenge**.

Dynamic Programming is a problem-solving technique used to solve complex problems by breaking them into smaller overlapping subproblems and storing their results to avoid repeated calculations.
